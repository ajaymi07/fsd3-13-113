# FS (File System)
it directconnect with client os than browser

## Major task of FS Module

- Reading and Writing  files
  - readFile()
  - writeFile()
  - appendFile()

- Directory mangement
  - mkdir()
  - rmdir()
  - rm()
  - readdir()
- Metadata/information
  - start()
  - lstat()
  - fstat()

- watching for changes 
  - watch()
  - watchFile() 
  - unwatchFile()

- Streaming Large File
  - createReadStream()
  - createWriteStream()

- File operation
  - rename()
  - truncate()
  - link()
  - unlink()
  - syslink()
